## openship release plan

Use this command with the arguments below.

```text
openship release plan [options]
```

| Option | Meaning |
| --- | --- |
| `--project <id>` | Bound project ID |
| `--event-key <key>` | Exact pending release event |
| `--manifest-commit <sha>` | Exact accepted production candidate or PRT base |

## openship release run

Use this command with the arguments below.

```text
openship release run [options] <run-id>
```

## openship release show

Use this command with the arguments below.

```text
openship release show [options] <plan-id>
```

## openship release start

Use this command with the arguments below.

```text
openship release start [options] <plan-id>
```

| Option | Meaning |
| --- | --- |
| `--idempotency-key <key>` | Stable key for this submission; preserve it on retry |
| `--confirm <environment>` | Type production for a production plan |

## openship release state

Use this command with the arguments below.

```text
openship release state [options]
```

| Option | Meaning |
| --- | --- |
| `--project <id>` | Bound project ID |
| `--fresh` | Read latest GitOps and runtime state |
